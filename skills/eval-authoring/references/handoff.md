# Eval suite handoff

Record each category independently.

```markdown
## Coverage and decisions
- Target skill and version:
- Coverage outline reviewed:
- Author-confirmed decisions:
- Outcome expectations:
- Adherence expectations:
- Unsupported expectations:

## Verification
- FastSkill version and compatibility status:
- Configuration validation command/result:
- Runtime observability command/result:
- Judge contrast labels and provenance:
- Executed calibration artifacts, or unverified reason:
- Authorized pilot scope:
- Pilot commands and run directories:
- Target passes/failures/errors/unmeasured evidence:

## Continuation
- Files changed:
- Preserved unrelated edits:
- Rescore, rejudge, or rerun decision:
- Missing prerequisites and next action:
```

Do not collapse these fields into “verified.” A reviewed and parse-valid suite may still be unexecuted; an executed trial may lack a judgment; a target failure may demonstrate a useful test.
