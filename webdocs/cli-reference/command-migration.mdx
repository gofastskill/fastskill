# Breaking command migration

FastSkill now uses an explicit `<namespace> <action>` command tree. This is a greenfield breaking
change: removed paths have no aliases or forwarding handlers. Update scripts, CI jobs, agent tool
names, and saved shell commands before installing this release.

## Command replacements

| Removed command | Replacement |
| --- | --- |
| `fastskill init` | `fastskill project init` |
| `fastskill install` | `fastskill project install` |
| `fastskill add SOURCE` | `fastskill skill add SOURCE` |
| `fastskill remove ID...` | `fastskill skill remove ID...` |
| `fastskill update [ID]` | `fastskill skill update [ID]` |
| `fastskill list` | `fastskill skill list` |
| `fastskill read ID` | `fastskill skill read ID` |
| `fastskill search QUERY` | `fastskill skill search QUERY` |
| `fastskill add BUNDLE.zip` | `fastskill bundle add BUNDLE.zip` |
| `fastskill list --bundles` | `fastskill bundle list` |
| `fastskill update --bundle ID --from FILE` | `fastskill bundle update ID --from FILE` |
| `fastskill remove --bundle ID` | `fastskill bundle remove ID` |
| `fastskill repos ACTION` | `fastskill repo ACTION` |
| `fastskill analyze ACTION` | `fastskill analysis ACTION` |
| `fastskill optimize ACTION` | `fastskill optimization ACTION` |
| `fastskill reindex` | `fastskill index rebuild` |
| `fastskill serve` | `fastskill server serve` |
| `fastskill doctor` | `fastskill cli doctor` |
| `fastskill completion` | `fastskill cli completion` |
| `fastskill spec` | `fastskill cli spec` |
| `fastskill mcp register` | `fastskill mcp install` |
| `fastskill SKILL_ID` | `fastskill skill read SKILL_ID` |

`bundle build` and `bundle override` keep their paths. `marketplace`, `eval`, `cache`, and `mcp`
keep their namespaces; their documented actions are unchanged.

## MCP tool names

MCP tool names mirror the complete command path. For example:

| Removed tool | Replacement |
| --- | --- |
| `fastskill_add` | `fastskill_skill_add` |
| `fastskill_remove` | `fastskill_skill_remove` |
| `fastskill_install` | `fastskill_project_install` |
| `fastskill_reindex` | `fastskill_index_rebuild` |
| `fastskill_repos_add` | `fastskill_repo_add` |
| `fastskill_optimize_run` | `fastskill_optimization_run` |

Restart MCP clients after updating their FastSkill binary so they refresh `tools/list`.

## Verify a migration

```bash
fastskill --help
fastskill skill --help
fastskill bundle --help
fastskill cli spec --format json
fastskill cli completion bash > fastskill.bash
```

Root help should show the 13 namespaces. `bundle --help` should list build, add, list, update,
remove, and override. Old root actions, plural `repos`, and bare skill IDs should fail as unknown
commands without changing files. Removed `mcp register` should also fail without changing an agent
configuration file; use `mcp install` instead.
