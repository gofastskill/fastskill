## Overview

`fastskill eval` runs skill quality checks using prompts and rubrics under `[tool.fastskill.eval]` in `skill-project.toml`. Subcommands are `validate`, `run`, `report`, and `score`.

<Callout type="info">
`eval run` requires an agent on `PATH` for the chosen `--agent` key. Known keys are `aikit`, `claude`, `codex`, `cursor`, `gemini`, and `pi`. A key is accepted only when its CLI is detected on the current machine, so a typo and an uninstalled agent both error with `RUNTIME_UNKNOWN_ID`, which lists what was detected. Use `eval validate --agent <key>` or `--all` to verify availability.
</Callout>

## Usage

```bash
fastskill eval <SUBCOMMAND> [OPTIONS]
```

## eval validate

Checks eval configuration and files (optional agent presence check).

```bash
fastskill eval validate
fastskill eval validate --agent codex
fastskill eval validate --all
fastskill eval validate --json
```

| Option | Description |
|--------|-------------|
| `--agent <AGENT>` | Verify the given agent(s) are available; repeatable. Mutually exclusive with `--all` |
| `--all` | Verify availability of every installed agent. Mutually exclusive with `--agent` |
| `--format <FORMAT>` | `table` or `json` only (eval does not support `grid`/`xml`) |
| `--json` | Shorthand for `--format json` |

With `--agent` or `--all`, both outputs report each selected agent: the table prints one `agent '<key>': available|unavailable` line per agent, and the JSON document carries an `agents` object keyed by agent id (`{"agents": {"claude": true}}`). An unavailable agent is an error unless `fail_on_missing_agent = false` is set in the eval config.

## eval run

Runs eval cases against an agent; writes artifacts under `--output-dir`.

```bash
fastskill eval run --agent codex --output-dir ./eval-runs
fastskill eval run --agent codex --agent claude --output-dir ./eval-runs
fastskill eval run --all --output-dir ./eval-runs
fastskill eval run --agent claude --output-dir /tmp/evals --case smoke-1
fastskill eval run --agent codex --output-dir ./evals --tag smoke --model gpt-4o
fastskill eval run --agent codex --output-dir ./evals --json --no-fail
fastskill eval run --agent codex --output-dir ./evals --trials 5 --threshold 0.8
fastskill eval run --all --output-dir ./eval-runs --ci --threshold 0.9
```

`--agent <key>` (repeatable) and `--all` are mutually exclusive — passing both errors with `RUNTIME_CONFLICTING_FLAGS`. `eval run` requires one of them (passing neither errors with `RUNTIME_NO_SELECTION`).

| Option | Description |
|--------|-------------|
| `--agent <AGENT>` | Agent key(s) to run; repeatable. Required unless `--all` is given |
| `--all` | Run against all installed agents. Mutually exclusive with `--agent` |
| `--output-dir <DIR>` | **Required.** Directory for run output |
| `--model <MODEL>` | Optional model override passed to the agent |
| `--case <ID>` | Run only this case id |
| `--tag <TAG>` | Run only cases with this tag |
| `--format <FORMAT>` | `table` or `json` only |
| `--json` | Shorthand for `--format json` |
| `--no-fail` | Exit zero even when the suite fails |
| `--trials <N>` | Override `trials_per_case` from the config for this run (1–1000) |
| `--threshold <F>` | Override `pass_threshold` from the config for this run (0.0–1.0) |
| `--ci` | CI mode: the suite passes when its overall pass rate meets the threshold, instead of requiring zero failed cases |
| `--no-isolation` | Run in the project root against the ambient agent environment (disables per-case isolation) |

### Environment isolation

By default every case runs **isolated**: the skill next to `skill-project.toml` is deployed alone into a per-case scratch workspace, and the agent's user-level skill discovery is suppressed where the backend supports it (claude, codex, pi). Scores then measure the skill under test rather than whatever else is installed on your machine. Isolation needs a `SKILL.md` beside `skill-project.toml` and a `[metadata].id` naming the skill — missing either is a `EVAL_ISOLATION_NO_SKILL` error, not a silent fallback.

The summary reports what each run actually got (`isolation:` line in table output, `isolation` object in `summary.json`), and a failed case's scratch workspace is kept under `<run-dir>/workspaces/` for debugging. Pass `--no-isolation` to restore the old inherit-everything behaviour.

Scores recorded before isolation existed were measured against the ambient environment — expect trigger rates to re-baseline on the first isolated run.

## eval report

Summarizes a completed run directory.

```bash
fastskill eval report --run-dir ./eval-runs/2026-04-01T14-32-10Z/claude
fastskill eval report --run-dir /tmp/evals/latest --json
```

| Option | Description |
|--------|-------------|
| `--run-dir <DIR>` | **Required.** The per-agent run directory — `<output-dir>/<timestamp>/<agent>`, the one that holds `summary.json` |
| `--format <FORMAT>` | `table` or `json` only |
| `--json` | Shorthand for `--format json` |

## eval score

Re-scores saved artifacts without invoking the agent again.

```bash
fastskill eval score --run-dir ./eval-runs/2026-04-01T14-32-10Z/claude
fastskill eval score --run-dir /tmp/evals/run-1 --no-fail
```

| Option | Description |
|--------|-------------|
| `--run-dir <DIR>` | **Required.** The per-agent run directory (`<output-dir>/<timestamp>/<agent>`) |
| `--format <FORMAT>` | `table` or `json` only |
| `--json` | Shorthand for `--format json` |
| `--no-fail` | Exit zero on suite failure |
