## Overview

`fastskill optimize` improves a skill document iteratively: each step scores the current `SKILL.md` against your eval suite, proposes patches, and keeps the best candidate. Subcommands are `run`, `resume`, `status`, `inspect`, and `export`. For the config file format and a walkthrough, see [Optimization](/optimize/overview).

<Callout type="info">
`optimize run` scores candidates with the same agent runtimes as `fastskill eval run`, so the agent named in your config must be on `PATH`. Use `fastskill eval validate --agent <key>` to verify availability.
</Callout>

## Usage

```bash
fastskill optimize <SUBCOMMAND> [OPTIONS]
```

## optimize run

Starts an optimization run from a config file.

```bash
fastskill optimize run --config ./optimize.toml
fastskill optimize run --config ./optimize.toml --out-dir ./optimize-runs
fastskill optimize run --config ./optimize.toml --resume ./optimize-runs/run-1
```

| Option | Description |
|--------|-------------|
| `--config <PATH>` | **Required.** Path to the optimize config file |
| `--out-dir <DIR>` | Override `out_dir` from the config file |
| `--resume <RUN-DIR>` | Resume from this run directory instead of starting fresh |
| `--no-isolation` | Score in a shared workspace against the ambient agent environment (disables per-case scoring isolation) |

## optimize resume

Resumes an interrupted run in place.

```bash
fastskill optimize resume ./optimize-runs/run-1
```

| Argument | Description |
|----------|-------------|
| `<run-dir>` | **Required.** Path to the run directory to resume |

## optimize status

Shows the state of a run: current step, scores, and whether it is still in progress.

```bash
fastskill optimize status ./optimize-runs/run-1
fastskill optimize status ./optimize-runs/run-1 --watch
```

| Argument / Option | Description |
|-------------------|-------------|
| `<run-dir>` | **Required.** Path to the run directory |
| `--watch` | Poll and re-render every ~2 seconds |

## optimize inspect

Shows the per-step artifacts of a run.

```bash
fastskill optimize inspect ./optimize-runs/run-1 --step 3
fastskill optimize inspect ./optimize-runs/run-1 --step 3 --show diffs
```

| Argument / Option | Description |
|-------------------|-------------|
| `<run-dir>` | **Required.** Path to the run directory |
| `--step <N>` | **Required.** Step number to inspect (0-based, matching `optimize status`) |
| `--show <MODE>` | `patches`, `diffs`, `gate`, `skips`, or `all` (default `all`) |

## optimize export

Writes the best skill document from a completed run to a file.

```bash
fastskill optimize export ./optimize-runs/run-1 --out ./SKILL.md
```

| Argument / Option | Description |
|-------------------|-------------|
| `<run-dir>` | **Required.** Path to the run directory |
| `--out <PATH>` | **Required.** Destination path for the exported skill document |
