## Prerequisites

- The `fastskill` binary on your `PATH` (see [Installation](/installation): Homebrew on macOS/Linux, Scoop on Windows, or release archives)
- `OPENAI_API_KEY` when you use embedding search or `index rebuild`

## Five-minute setup (CLI)

### 1. Install the CLI

Follow [Installation](/installation), then confirm:

```bash
fastskill -V
```

### 2. Create a manifest

Create the skill you'll manage, then a `skill-project.toml` at your project root:
```bash
mkdir -p skills/demo-skill
cat > skills/demo-skill/SKILL.md << 'EOF'
---
name: demo-skill
description: A demo skill for the quickstart
---

This is a demo skill.
EOF
```

```toml skill-project.toml
[dependencies]
demo-skill = { origin = { type = "local", path = "./skills/demo-skill", editable = true }, groups = ["dev"] }

[tool.fastskill]
skills_directory = ".claude/skills"
```

<Callout type="info">
`[tool.fastskill].skills_directory` is required for a project-level manifest — without it, `project install`/`skill search`/etc. fail with a `Configuration error`. `fastskill project init --skills-dir <path>` writes this for you; the manifest above is the hand-written equivalent.
</Callout>

### 3. Add a skill

Pick the source that matches your workflow:
```bash
# From a public registry ID (requires a configured repository — see 'fastskill repo add'
# below, or /registry/overview)
fastskill skill add pptx@1.0.0 --repository public

# From a local folder (editable for dev)
fastskill skill add ./skills/demo-skill -e --group dev

# From git with a branch (replace with a real repository URL)
fastskill skill add https://github.com/your-org/your-skill.git --branch main
```

<Callout type="info">
Skills added with `-e`/`editable = true` are links to their source directory. FastSkill validates
the link target and identity but labels the content mutable instead of claiming a verified digest.
</Callout>

### 4. Install & index

```bash
fastskill project install
fastskill index rebuild
fastskill skill list --check
```

### 5. Search & verify

```bash
fastskill skill search "demo" --local --format json
```

<Callout type="success">
You should see a JSON result for `demo-skill`. If it is empty, run `fastskill project install`, then
`fastskill index rebuild`, and search again. `skill list --check` reports editable content as mutable while
still checking its link, identity, constraint, and dependency structure.
</Callout>

### 6. Optional: serve UI

```bash
fastskill server serve --port 8080
```
Browse `http://localhost:8080/` for the bundled UI.

The HTTP API is available under `/api/v1/…`, e.g.:
- `GET http://localhost:8080/api/v1/skills` — list installed skills
- `GET http://localhost:8080/healthz` — liveness probe
- `GET http://localhost:8080/readyz` — readiness probe

### 7. Optional: share the setup as one bundle

Teams can add a `[bundle]` declaration to `skill-project.toml`, then package the selected
skills and their dependency closure:

```bash
fastskill bundle build --output dist
fastskill bundle add dist/<bundle-id>-<version>.zip
fastskill bundle list
```

Continue with the [bundle guide](/cli-reference/bundle-command) for a complete manifest, updates,
locked restoration, removal, and personal overrides.

## Use-case quick recipes

- **Install skills from different sources**
  - Public repository ID: `fastskill skill add pptx@latest --repository public`
  - Local folder (editable): `fastskill skill add ./skills/my-skill -e --group dev`
  - Git repo with branch: `fastskill skill add https://github.com/your-org/your-skill.git --branch main`
  - Private Git marketplace:
    ```bash
    fastskill repo add team --repo-type git-marketplace https://github.com/your-org/your-skills.git --priority 1
    fastskill project install
    ```

- **Add standard-compliant skills (SKILL.md only)**

  This assumes you're inside a project that already has a `skill-project.toml`
  with `[tool.fastskill].skills_directory` set (e.g. from the walkthrough above,
  or `fastskill project init`) — `fastskill skill add` needs one to know where to install into.
  ```bash
  # Create minimal skill
  mkdir my-first-skill
  cd my-first-skill

  cat > SKILL.md << 'EOF'
  ---
  name: my-first-skill
  description: A simple skill following the AI Agentic Skills Standard
  ---

  This is my first skill!
  EOF

  # Add it to fastskill
  fastskill skill add .
  ```

  FastSkill will:
  - Extract the skill ID from SKILL.md (`name` or `metadata.id`)
  - Extract version from SKILL.md (`metadata.version` or `version`, defaulting to `1.0.0`)
  - Warn if SKILL.md is missing optional fields (e.g. `compatibility`) — harmless, not an error

## Troubleshooting

- **No skills found**: ensure `skill-project.toml` exists at project root and rerun `fastskill project install`.
- **`Configuration error: ... requires [tool.fastskill] with skills_directory`**: your manifest is missing that field. Run `fastskill project init --skills-dir <path>` at the project root, or add `[tool.fastskill]` / `skills_directory = "..."` by hand (see step 2).
- **Search returns nothing**: run `fastskill index rebuild` after adding or installing skills and verify
  that an embedding provider is configured.
- **Binary not on PATH**: reinstall or move the binary to a directory in PATH (e.g., `~/.local/bin`).
